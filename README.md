# ANBI Atlas data

`anbi_atlas_nederland.csv` — one row per Dutch place, with a count of currently
active ANBI's (public-benefit organisations registered with the Belastingdienst)
and a geocoded latitude/longitude for that place.

Published by [Donateursbelangen](https://donateursbelangen.nl) for use in the
[ANBI atlas](https://umap.openstreetmap.fr) map. Rebuilt weekly from the
official Belastingdienst ANBI register and KvK data; only aggregated per-place
counts are published here, no per-organisation data.

Direct raw-file link (for uMap / website embedding):
`https://raw.githubusercontent.com/jordanvanbergen/anbi-atlas/main/anbi_atlas_nederland.csv`
